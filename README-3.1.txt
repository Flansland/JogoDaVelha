JOGO DA VELHA 3.1

Novidades:
- Nova logo enviada pelo dono.
- Visual continua no estilo azul/creme do projeto e pode receber temas da loja.
- Loja com preview de imagem por URL.
- Presente de moedas por ID.
- Presente de item da loja por ID.
- Notificacoes de presentes, codigos e acoes do Admin.
- Admin pode dar/retirar moedas, XP e nivel.
- Admin pode dar item da loja.
- Admin pode criar codigos de moedas/XP.
- Admin pode criar temas, inclusive imagem de fundo por URL.
- Admin pode criar pacotes.
- Modo manutencao liga/desliga para todos os clientes.
- Sistema de versao e publicacao de APK pelo painel.
- O jogador verifica atualizacao e abre o instalador do Android.
- Builds Player e Admin ficam em pastas separadas.
- Nome exibido configuravel para Jogo Da Velha.

IMPORTANTE SOBRE ATUALIZACAO:
O Android normalmente exige confirmacao/permissao para instalar um APK baixado fora da loja. O app nao consegue fazer uma instalacao silenciosa comum.
O servidor atual guarda o APK no filesystem. Em hospedagens com filesystem efemero, como planos sem disco persistente, o APK pode desaparecer depois de reinicio/redeploy. Para producao, use armazenamento persistente ou um armazenamento de objetos/GitHub Release.
